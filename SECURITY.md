## Reporting Security Issues

Email security reports to [gongzerui@team6907.org](mailto:gongzerui@team6907.org).

**Do not report security vulnerabilities through public GitHub issues.**

GenieTerm is a private product fork of [Wave Terminal](https://github.com/wavetermdev/waveterm). Please do not send GenieTerm reports to Command Line Inc. / `security@commandline.dev`.
