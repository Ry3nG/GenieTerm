# GenieTerm 1.5.1

This update fixes Windows file operations and PowerShell completion, adds native listening-port discovery, and makes keyboard hints match the Windows shortcuts. It also preserves NTFS file metadata when saving edited files and restores remote terminals after a slow helper update.

## Windows files

- Renaming a file keeps it in its original directory, including paths with backslashes, spaces and Unicode characters.
- Quoted file-name and full-path copy actions use PowerShell quoting for local Windows files. Remote Unix files keep their shell quoting.
- Opening a file in its default application preserves literal `~` characters inside its path.
- Uploads and downloads preserve local Windows drive paths when a Linux or macOS helper handles the other end of the transfer.
- Copying a directory into itself is rejected even through a different path spelling or a directory junction. Case-sensitive Windows directories remain distinct.
- Editor saves preserve existing hard links, access-control lists and alternate data streams. Replacement failures retain the original contents or report the location of a recovery copy.

## PowerShell and keyboard controls

- Completion recognizes drive paths, network-share paths, quoted names and literal special characters.
- Command and parameter suggestions use the active PowerShell edition, including Windows PowerShell 5.1 and PowerShell 7. Cmdlet aliases and common parameters are supported.
- Windows command-palette and shortcut-editor hints show the actual Alt/Ctrl modifiers.
- Changing the Ctrl+V paste setting takes effect in existing tabs.
- Command AI and command-card reruns replace known PowerShell prompt text without inserting Unix control characters. Unknown prompt text is left for the user to clear.
- Process-linked CLI badges now work on Windows and clear when their process exits.
- Closing the final block in a tab no longer tries to update its deleted layout.

## Host view

- Windows Hosts now list IPv4 and IPv6 TCP listeners with process information. Inaccessible process details are marked as partial results.
- The overview includes the Windows version and CPU model.
- Process rows include Windows account names when access permits, with bounded account-name lookup.

## Remote sessions

- Terminals reconnect when a background remote-helper update finishes after SSH has already connected, so an existing durable session can resume without an extra keypress.

## Installation and validation

Download the Windows x64 EXE for per-user installation, or the ZIP for an unpacked copy. Install over an existing version to retain settings and workspaces. Windows packages remain unsigned; a Microsoft Store account or paid certificate is not required.

See [Windows validation](https://github.com/Ry3nG/GenieTerm/blob/main/docs/windows-validation.md) for the tested flows and remaining platform-specific limits. macOS and Linux packages continue to ship with this release.
