# GenieTerm 1.0.1

The Host view now fits whatever space you give it, from a tall side pane to a full-screen block.

## Host at any size

- **Its own width, not the window's.** Layout follows the block's own width, so splitting a tab or dragging a divider rearranges Host the same way on a laptop or a large display.
- **Narrow blocks.** The host name gets its own row and the Overview / Processes / Ports tabs stretch across the block. Resources switch to a scrollable strip that keeps your selection in view. Before, the side list stayed open in narrow blocks and squeezed the detail until text overlapped.
- **Many GPUs, little room.** On a host with three or more GPUs, a narrow block shows one compact row per GPU (utilization, memory, temperature and power) instead of a stack of tall cards, so CPU and memory are still a short scroll away. Cards return once there is room for them side by side.
- **Short panes** drop the host's subtitle line (it is still on hover) so more of the view shows.
- **Ports** switch to icon buttons when narrow and wrap a forward's address under the service name instead of cutting it off.
- **Processes** keeps Command, CPU% and Memory visible at any width, and adds PID, User, Status and threads back as space allows.
- Process tables in the CPU, memory and GPU pages drop the PID, then the owner, as they narrow, and history charts get shorter in narrow blocks.

## Fixes

- Container disks: hosts that ran a pre-release 1.0 helper now get the current one, so FUSE shares such as `/mnt/afs` and container volumes appear under Disks.

## Install and update

- macOS (Apple Silicon and Intel). The app is not notarized: after the first launch attempt, allow it under System Settings → Privacy & Security → "Open Anyway".
- GenieTerm 0.4.83 and later update in the app.
