# GenieTerm 1.2

Command AI now works with the AI you already have, Codex, Claude Code, Ollama or your own API key, and it can fix and explain commands, not just write them.

## Command AI

- **Bring your own AI.** Choose Codex or Claude Code to use the sign-in you already have, Ollama to keep everything on your own hardware, or an API key for OpenAI, OpenRouter, Gemini, LM Studio, Anthropic or any OpenAI-compatible server. GenieTerm finds the tools installed on your computer and shows whether you're signed in. It never picks one for you. API keys are kept in your system keychain.
- **Fix with AI.** Click the sparkle on a failed command. Command AI reads the command, its exit code and the end of its output, says what went wrong in a sentence or two, and offers commands that fix it.
- **Explain.** The same sparkle on a successful command explains what it did. To explain anything on screen, select it and choose **Explain Selection with AI** from the context menu.
- **Commands that fit the machine.** Requests include the host's operating system, distribution and shell, so you get `apt` on Ubuntu, `dnf` on Fedora, and BSD flags on macOS. This also works on SSH hosts without the genie helper.
- **Refine instead of retyping.** After an answer, type a follow-up such as "only in src" or "sort by size".
- **Insert, run or copy.** ↵ puts the command at your prompt, ready to edit. ⌘↵ runs it, and ↑↓ moves between suggestions. Commands that delete files, run as administrator, run code from the internet, force-push or erase disks are labelled, and they need a second confirmation before they run. GenieTerm still never runs anything on its own.
- **Type a request at the prompt.** If something like "show disk usage" fails as a command, a one-line suggestion appears under the terminal. You can turn this off.

## Privacy

- Nothing is sent until you ask, and requests go straight from your computer to the AI you chose.
- Before anything leaves, GenieTerm replaces keys, tokens, passwords, private keys and credentials in URLs with `[REDACTED]`. A remote host is described only as "Remote host over SSH", never by its name.
- **What's sent** in the Command AI sheet shows the exact request. Output from a failed command is included only while the "Include output" box is checked.
- You can turn Command AI off for particular hosts, such as production servers, or switch it off entirely.

All of this lives in the new **Settings → Command AI**.

## Upgrading from 1.1

Command AI used to call ChatGPT's service directly with your Codex login. That service was never a public API, so 1.2 runs your Codex CLI instead. The first time you open Command AI, pick Codex (or another AI) once and you're set.

## Also

- The helper install prompt now describes GenieTerm's genie helper instead of "Wave Shell Extensions", and its buttons say **Install** and **Don't Install**.
- On Linux and Windows, the shortcuts in the feature tour now show Alt rather than Ctrl, which is what the keybindings actually use.
- The shell-integration sparkle in terminal headers is now a Command AI button.
- Tab completion no longer asks an AI for suggestions, so it stays instant.

## Install and update

- **macOS** (Apple Silicon and Intel): the app is not notarized. After the first launch attempt, allow it under System Settings → Privacy & Security → "Open Anyway". GenieTerm 0.4.83 and later update in the app.
- **Linux:** download the AppImage or .deb for your architecture from this release. AppImage installs update themselves. A .deb install shows **Update Available** and points you to the new package.
- **Windows x64** remains an unsigned preview published on prerelease tags.
