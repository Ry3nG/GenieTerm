# GenieTerm 1.0

GenieTerm 1.0 is the terminal for people who live in SSH: command blocks over a real shell, SSH sessions that survive sleep and network drops, remote files in the same workspace, and now the machine itself, with its GPUs, processes and ports, one click away. No account, no telemetry.

## Highlights

- **Host.** One view per machine (this Mac or any SSH host, containers included) with Overview, Processes and Ports. Overview opens on a summary of CPU, memory, network, disks and every NVIDIA GPU; pick any of them from the side list for a full view with larger history charts and its top processes. A GPU's page adds memory bandwidth, clocks, fan, performance state and every process holding it, with its owner. Disks lists each volume once, NFS and FUSE shares and container volumes included. Ports lists what is listening and who owns it, naming Jupyter, TensorBoard, Postgres and others, and tucks system services and other users' sockets away. It samples only while you look at it.
- **Port forwarding without `ssh -L`.** On an SSH host, Forward & open puts a remote port on `localhost` and opens it in your browser. Forwards listen on 127.0.0.1 only, wait out reconnects, and show how many connections they carry.
- **Know when it's done.** When a command runs longer than 10 seconds and you're looking elsewhere, GenieTerm sends a notification with how it ended and how long it took. Click it to go back to the tab and block. Settings → General → Terminal sets the delay, or turns it off.
- **Knows where you are.** Terminal headers show the working directory and the git branch (ahead/behind, and a dot when there are changes). Click the directory to open it in Files on the same machine. Tabs name themselves after the folder you're in until you rename them.
- **Files and Host follow you.** Opening Files or Host from the rail or the palette uses the focused terminal's connection, and Files opens in its directory.

## Also new

- **A command palette worth opening.** Commands are grouped, searchable by name, keyword or initials ("sbr" finds Split Block Right), and recently used commands come first. Saved SSH connections appear as Connect items.
- **Settings you can click.** Settings → General covers appearance, terminal, sessions, window and updates, and every change applies at once. Raw JSON is a tab away.
- **Files that read like Finder.** The directory table fills the block, drops columns gracefully when it is narrow, and shows kinds (Folder, Markdown, TypeScript), sizes like 2.1 KB and dates like Today 09:41.
- **Transfers at a glance.** Each upload and download is one row with a progress bar, a status, and the reason if it failed, with cancel and retry in reach.
- **Calmer status.** A command you stop with Ctrl-C is marked Interrupted instead of failed.
- **Command AI that shows what it can do.** The composer suggests example requests before you type.
- **A welcome and tour that say what GenieTerm is.** People updating from 0.x see a short card with what's new.
- **Markdown previews** keep a readable line length.

- **A helper that keeps itself current.** GenieTerm's small remote helper (`~/.genieterm/bin/genie`) now carries a protocol stamp. A host with an older or broken copy gets the current one on the next connect, and the Host view offers Update helper or Install helper in place, without dropping your terminals.

## Removed

- **The Git panel.** Git belongs in your terminal, and the branch is now in every terminal header. The panel's "run any git arguments" backend call is gone with it.
- **Web on the widget rail.** The rail is now Terminal, Files and Host, and it is shown by default. The web view is still in the palette and behind `genie web`.
- Sysinfo and Processes blocks saved by earlier versions open as the Host view.

## Performance

- **One renderer per window.** Tabs now share their window's renderer instead of each starting its own. With five tabs open GenieTerm uses under 700 MB instead of about 1.2 GB, and each extra tab costs about 26 MB instead of about 150 MB.
- **Hidden tabs stay quiet.** Background tabs stop drawing, release their GPU contexts after ten seconds, and pause system-info and process polling.
- **Fast switching.** A recently used tab appears in about 70 ms with its scrollback, selection and running programs intact. Tabs beyond the cache (`window:maxtabcachesize`: 10 by default, fewer on machines with 16 GB of memory or less) are rebuilt from their history when you return.
- Typing latency and output throughput are unchanged from 0.5.
- The Host view draws its charts with a few lines of SVG instead of a charting library, so the app no longer ships @observablehq/plot and d3.
- If a tab misbehaves, launching with `GENIETERM_LEGACY_TABVIEWS=1` restores one renderer per tab.

## Fixes

- A new terminal picks up its starting folder right away. Before, its header and tab name could stay blank until the first `cd`.
- SSH config aliases with underscores in the name (such as `lab_gpu`) connect. Before, they stayed disconnected without an error.
- A leftover helper that crashes on start is replaced instead of failing the connection, and interrupted installs no longer leave temporary copies behind in `~/.genieterm/bin`.
- Connecting to a Mac without the helper installs it instead of failing to read the version check.
- The process list shows full names on macOS and Linux ("Google Chrome Helper (Renderer)", not "Google Chrome He").

## Install and update

- macOS (Apple Silicon and Intel). The app is not notarized: after the first launch attempt, allow it under System Settings → Privacy & Security → "Open Anyway".
- GenieTerm 0.4.83 and later update in the app.
- Windows x64 remains an unsigned preview published on prerelease tags.
