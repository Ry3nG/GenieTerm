# GenieTerm 1.3

Quick Start is a one-minute tour that happens in your own terminal. You run a command, ask Command AI for one, and open a folder, and it moves on as you do. A couple of tips also appear the first time they're useful.

## Quick Start

- **Learn by doing.** Instead of a slideshow, a small card points at the real controls and waits for you: run a command, ask Command AI, open the folder you're in. Each step moves on when you actually do it.
- **Three steps.** Run a command and meet the command block. Ask Command AI for a command and insert it at your prompt. Click the folder name in the terminal header to open it in Files. The last card points to SSH connections and Host.
- **Never in the way.** The card never covers your prompt or takes over the keyboard. Every step can be skipped, and closing the card saves your place.
- **Setting up Command AI is part of it.** If you haven't chosen an AI yet, Quick Start walks you through picking Codex, Claude Code or another engine. Nothing is sent until you press Return.
- **Come back any time.** Run **Quick Start** from the command palette (⇧⌘P, or Alt+Shift+P on Linux and Windows) to pick up where you left off or start again.

## Tips when they help

- The first time a command fails, a tip points to the sparkle that explains what went wrong and suggests a fix.
- The first time you connect to a server, a tip shows that Files and Host now open on that machine.
- Each tip appears once, at most one per session, and never while Quick Start is running.

## Welcome and What's New

- New installs get a shorter welcome: one page, then Quick Start. The four-page feature slideshow is gone.
- Updating from an earlier version shows what's new in 1.3, with **Start Quick Start** and **Not Now**.

## Install and update

- **macOS** (Apple Silicon and Intel): the app is not notarized. After the first launch attempt, allow it under System Settings → Privacy & Security → "Open Anyway". GenieTerm 0.4.83 and later update in the app.
- **Linux:** download the AppImage or .deb for your architecture from this release. AppImage installs update themselves. A .deb install shows **Update Available** and points you to the new package.
- **Windows x64** remains an unsigned preview published on prerelease tags.
