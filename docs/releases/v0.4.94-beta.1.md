# GenieTerm 0.4.94 beta 1

This prerelease introduces a Windows x64 preview alongside the macOS packages. It is intended for evaluation before the Windows stable-release gate is complete.

## Windows downloads

- Use `GenieTerm-win32-x64-0.4.94-beta.1.exe` for a normal per-user installation.
- Use `GenieTerm-win32-x64-0.4.94-beta.1.zip` for an unpacked copy.
- Download both only from this repository's GitHub Release page.

The Windows preview is unsigned. [Windows Defender SmartScreen](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation) may show an unrecognized-app warning. This prerelease does not satisfy the signed `v1.0.0` release gate. Remote folder downloads use the [Windows OpenSSH Client](https://learn.microsoft.com/en-us/windows-server/administration/openssh/openssh_install_firstuse) (`scp.exe`), which may need to be enabled as an optional Windows feature.

## Validation and limits

The release workflow must pass native Windows x64 tests, package identity and SHA-512 verification, and a packaged-app PowerShell command smoke before these files are published. The GitHub Release assets and update metadata are read back after publication.

An installed-app check on a clean Windows 11 x64 desktop, remote durable-session and file-transfer workflow checks, and an update from a prior Windows install remain required for the stable Windows release.

This beta is installed and updated manually from its GitHub Release page. The automatic updater's beta-channel path has not been validated.
