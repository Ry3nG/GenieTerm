# GenieTerm 1.7

More reliable terminal input and remote transfers, visible output gaps after SSH reconnects, and a lightweight way to continue a Command AI task in Codex or Claude Code.

## Terminal and SSH recovery

- Replace prompt input through the shell's native editing functions, including vi insert and command modes. Older shell integrations keep working; unsupported prompt replacement explains when to open a fresh shell.
- Keep explicit remote-session controls and closing responsive when a large paste fills the PTY input buffer. Normal input bytes retain their ordering. Existing remote managers keep their original implementation until replaced.
- Show an output-gap notice when a reconnect detects that some output is no longer retained on the remote host. The notice reports missing bytes without inserting text into the terminal stream.

## Remote files

- Download folders through the existing authenticated connection, with transferred-byte and completed-file feedback. A separate system SSH login, rsync or scp installation is no longer required for this operation.
- Preserve cancellation, retries and destination-conflict choices. Unknown directory totals are shown as bytes and files rather than an estimated percentage.
- Stream copies from SFTP-only hosts to helper-enabled hosts when the destination supports SFTP, including directories and files larger than 32 MiB. Hosts without an SFTP subsystem retain the bounded legacy fallback and its explicit limits.

## Continue in an AI terminal

- Review sanitized task context, then choose **Copy context & open Codex** or **Copy context & open Claude**.
- The new terminal inherits the current host and working directory. Paste the copied context into the CLI when ready; the context is not placed in process arguments or saved terminal metadata.
- The chosen CLI must be installed and available in the destination terminal's PATH. Finding a local CLI does not imply that it is installed on a remote host.

## Performance evidence and compatibility

- Repeat packaged-app measurements and retain raw runs with summary statistics. Exercise foreground echo during background terminal output without counting another terminal's output as an echo.
- Collect macOS performance reports in CI without imposing arbitrary latency thresholds on shared runners.
- Keep settings, saved workspaces, command history and the existing remote-manager wire protocol compatible. No new account, background agent service, workflow templates or command recipes are introduced.
