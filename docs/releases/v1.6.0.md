# GenieTerm 1.6

Reuse commands and workspace layouts, inspect command output, and manage remote sessions and saved port forwards from one workspace. This release adds a local command library, workspace setups and batch file actions, with fixes for completion, destination preservation and cross-platform download names.

## Command history and recipes

- Search the latest 500 commands by text, host, folder and result. Open retained original output or insert a command into an idle shell prompt without running it.
- Save up to 100 local command recipes with text or choice arguments. Preview the destination and resolved command before insertion; supported shells quote argument values literally.
- History and recipes are shared across windows and stored locally. Clearing history does not delete recipes, and terminal output is not stored in the command library.
- Command-library insertion requires a confirmed idle shell prompt. Multiline insertion also requires bracketed paste support.

## Output and completion

- Inspect a fixed snapshot of a command's output, search and copy it, or jump back to its retained terminal output. Snapshots include up to the last 2,000 rows and 256K characters.
- Manual completion is available from the terminal menu. Selection stays stable during unrelated background refreshes, Escape discards pending requests, and IME composition is left to the terminal.
- Shift-right-click opens the terminal menu when right-click paste is enabled.
- PowerShell command markers stay aligned with pending Windows terminal output.

## Workspace setups

- Save pane types, layout proportions, hosts and folders, then open a fresh workspace from that setup.
- Each pane keeps its saved host and folder by default. Optional overrides can move the setup to another host or folder, including this computer.
- Setups exclude commands, environment variables, credentials and running-session identities. They also bypass configured startup widgets when creating their panes.

## Remote sessions and saved services

- The Host view lists GenieTerm's known durable SSH sessions with connection and exit state, plus actions to open or reconnect their terminals.
- Save named port-forward definitions with remote endpoints and local-port preferences. Automatic restoration is opt-in and runs once per new SSH connection.
- Explicitly stopped tunnels and failed binds are not repeatedly restarted on the same connection. Restore failures remain visible, and forgetting a definition leaves an existing tunnel running.

## Batch file actions

- Select multiple files or folders for queued copies or downloads, with progress, retry and cancellation controls.
- Batch downloads choose a local destination once and offer Keep both or Skip existing for name conflicts.
- Download planning handles case and Unicode aliases on macOS and rejects reserved or ambiguous Windows filenames.

## Updates

macOS, Linux and Windows packages continue to use the stable update feed. Existing settings and workspaces remain compatible. macOS packages remain ad-hoc signed and Windows installers remain unsigned unless release signing is configured.
