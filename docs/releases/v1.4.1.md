# GenieTerm 1.4.1

Port forwarding in Host now connects to the address where your remote server is listening, including Tailscale and other specific network interfaces. Forwarding status turns green after the tunnel successfully connects to the remote service.

## Port forwarding

- **Use the server's listening address.** Forward & open supports services bound to a specific IPv4 or IPv6 address, as well as localhost and all-interface listeners.
- **Keep services distinct.** Services using the same port on different interfaces have their own forwarding status and actions.
- **Show connection status accurately.** New forwards and forwards after an SSH reconnect wait for a successful remote connection before showing green. Connection failures show the target address.

## Update

Existing macOS and Linux AppImage installations receive this release through the stable update feed. Linux .deb installations show an update notice with a link to the new package.
