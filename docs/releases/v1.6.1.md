# GenieTerm 1.6.1

Discover the features added in GenieTerm 1.6 with an upgrade introduction and a six-step walkthrough that opens the actual tools in your workspace.

## Learn the new features

- After upgrading, existing users see the new command history and recipes, output inspector, workspace setups, remote session and saved-forward management, and batch file actions.
- Choose **Try new features** to open each tool from a small guide while continuing to use the workspace. The guide never runs a command or starts a transfer for you.
- Go back, skip a step, or finish later. Progress is saved across restarts. Open **What's New in GenieTerm 1.6** from the command palette to resume or replay the walkthrough.
- If a terminal or retained output is unavailable, the guide explains what to do before trying again.
