# GenieTerm 1.7.3

CPU usage in Processes now clearly distinguishes individual process usage from total CPU usage, so values above 100% are easier to understand.

## CPU usage

- The process column is labeled **CPU% (1 core)**. Its tooltip explains that 100% means one fully used core and multithreaded processes can exceed 100%.
- The summary is labeled **Total CPU**. Its tooltip now correctly explains the 0–100% scale across all CPU cores.
- Both wide and compact layouts use the corrected labels and tooltips. CPU calculations are unchanged.
