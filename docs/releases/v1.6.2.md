# GenieTerm 1.6.2

A smaller, faster terminal: command recipes and workspace templates are removed, startup avoids unnecessary browser storage work, and terminal input stays ordered without building a separate RPC backlog for every keystroke.

## Focus on the terminal

- Remove the command recipe editor, parameter engine, save actions and persistence operations.
- Remove workspace templates, their menus, creation logic and dedicated backend methods. Existing workspaces still restore normally.
- Keep compact command history, output search, SSH sessions, remote files and port forwarding.
- Upgrades open directly into your workspace. The optional walkthrough is available from the command palette and now covers four retained tools.

## Startup, input and memory

- Avoid initializing browser local storage for unused state utilities and persisted production debug filters. Runtime debug controls remain available.
- Store recent command-palette actions in existing client metadata, avoiding a synchronous browser-storage open when the palette is first used. Its old ranking starts fresh.
- Send the first terminal input immediately and combine subsequent input waiting on an in-flight RPC. Unicode, control keys and input order are preserved for local and SSH terminals.
- Load command history only on first use, write snapshots asynchronously, and release each renderer's history snapshot when its panel closes.

On one Apple M3 Pro, five warm-profile relaunches per version reduced the median time to the terminal element from 5.11 seconds in 1.6.1 to 1.21 seconds in 1.6.2 (76%). This measures app startup, not SSH handshake time; results vary by machine.

## Compatibility

- Import command history into `command-history.json` on first use. The original `command-library.json` remains untouched; retired recipes are not imported.
- Preserve existing workspaces, settings, terminal output and remote-session protocol compatibility.
- Allow the Windows PowerShell quoting integration test enough time for the shell's first startup while retaining its process timeout and exact output checks.
