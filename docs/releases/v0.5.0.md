# GenieTerm 0.5.0

A hardening release ahead of 1.0: safer terminal input, SSH sessions that reconnect on their own, data-safe remote file operations, and a cleaner, quieter app.

## Terminal

- Enter always runs what you typed. Natural-language lines are no longer intercepted; when a line fails with "command not found", GenieTerm offers a proposed command instead. The composer (`Cmd+Shift+Space`) is unchanged.
- Re-run and inline "Run" are disabled while another command or a full-screen program is running, so they can't type into it.
- Commands that end without reporting an exit status (for example `exit`, a dropped SSH link, or a nested shell) are marked "Interrupted" instead of running forever.
- Completion no longer applies stale suggestions, ArrowRight only accepts at the end of the line, and history completion matches everything you typed.
- `Cmd+K` keeps command blocks for the next command; changing terminal settings no longer resets the terminal.
- PowerShell reports command blocks (preview; not yet tested on every PowerShell setup).
- Shell integration works with `set -u` / `setopt nounset`, keeps `$?` for prompt frameworks such as starship and oh-my-posh, and fixes long commands in fish on Linux.

## Remote sessions

- SSH connections reconnect automatically with backoff after a network drop or sleep/wake, and the connection overlay shows the next attempt with a Cancel button.
- Connection handshakes time out instead of hanging, and Disconnect can always abort an attempt.
- Hosts without the GenieTerm helper get SSH keepalives and no longer show as degraded.
- Closing a window, deleting a workspace, or switching a block's connection now asks first when it would end running durable sessions.
- Host-key errors show the `known_hosts` file, the SHA256 fingerprint, and the `ssh-keygen -R` fix. `ProxyCommand` reports that it isn't supported instead of silently connecting directly.
- New connection settings: `ssh:connecttimeout`, `ssh:serveraliveinterval`, `ssh:serveralivecountmax`.

## Files and transfers

- Saving and copying never destroy the original on failure, and saving through a symlink updates the real file.
- Deleting through SFTP no longer follows a symlinked folder. Every delete asks first and names the path.
- Saving detects that the remote file changed and offers Overwrite, Reload, or Cancel.
- The 32 MB upload limit is gone, and folders can be uploaded.
- Cancelling a folder download no longer quits the app; Retry works for downloads and uploads.
- Folder downloads honor SSH ports and GenieTerm connection settings, and quote remote paths safely.
- Windows drag-and-drop uploads build correct file paths.

## Privacy and resources

- GenieTerm sends no usage data. Telemetry and the Wave cloud endpoints are removed.
- The process viewer and system info sample only while they are on screen.

## Install and update

- macOS (Apple Silicon and Intel) only. The app is not notarized: after the first launch attempt, allow it under System Settings → Privacy & Security → "Open Anyway".
- Updating from 0.4.83 or later happens in the app. From 0.5.0 on, if a later update can't be installed (for example, the app runs from a disk image or a folder you can't write to), GenieTerm keeps running and offers the download instead.
- From 0.4.82 or earlier, download the zip from this page and replace the app manually.
- Windows x64 remains an unsigned preview published only on prerelease tags.

Building from source now needs Go 1.27 or newer.
