# GenieTerm 1.5

Windows x64 joins GenieTerm's regular GitHub releases with a per-user installer and an unpacked ZIP. This release improves native PowerShell interaction, terminal exit reporting, and Windows file navigation, and updates the components used to render diagrams and Markdown.

## Windows downloads

- Download `GenieTerm-win32-x64-1.5.0.exe` for a normal per-user installation.
- Download `GenieTerm-win32-x64-1.5.0.zip` for an unpacked copy.
- Existing Windows preview users can install the new EXE over their previous installation. Saved workspaces and settings are retained.

Windows packages are unsigned. Windows may identify the publisher as unknown or display a SmartScreen warning. Obtain the installer from this repository's GitHub Release page. A Microsoft Store account is not required.

## PowerShell and files

- Files dragged into PowerShell are quoted correctly when their paths contain spaces, apostrophes, or Unicode characters.
- Parent-directory navigation handles Windows drive roots and network shares, and terminal labels recognize native Windows home paths.
- PowerShell integration status explains when PSReadLine is needed for command blocks.

## Reliable terminal status

- Short-lived Windows terminal processes retain their actual exit status after ConPTY cleanup.
- Terminal output is drained on normal exit, while explicitly closing a busy terminal does not wait for an output reader.
- Repeated waits preserve failures instead of turning them into success.
- SSH command results preserve successful exits, nonzero statuses, and termination signals.
- Initial terminal resizing waits for controller setup, including when a new panel is resized during startup.

## Windows profile paths

Local communication uses a named pipe restricted to the current Windows user. Long data and configuration paths containing spaces or Unicode no longer hit the Unix socket path limit. Existing profile locations, settings and RPC authentication remain compatible.

## Rendering dependencies

DOMPurify is updated to 3.4.17 and KaTeX to 0.18.2 to address published security advisories without a major Mermaid upgrade.

## Updates

Installed Windows copies use the stable GitHub update feed. The EXE can also be installed manually over an existing installation. Windows remote-folder downloads require the Windows OpenSSH Client (`scp.exe`).

macOS and Linux downloads and their update channels remain available in the same release.
