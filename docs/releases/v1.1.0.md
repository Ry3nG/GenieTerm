# GenieTerm 1.1

GenieTerm now runs on Linux.

## Linux

- **AppImage and .deb, for x64 and arm64.** The builds target glibc 2.28, so they run on Ubuntu 20.04, Debian 10 and later.
- **AppImage** needs no install: make it executable and run it. It updates itself, the same way the macOS app does. Ubuntu 22.04 and later need the `libfuse2` package (`libfuse2t64` on 24.04) to run AppImages.
- **.deb** installs with `sudo apt install ./GenieTerm-linux-x64-1.1.0.deb`. GenieTerm puts itself in the app menu and on your `PATH` as `genieterm`. Because your package manager owns a .deb install, GenieTerm doesn't replace its files. Instead it shows **Update Available** in the tab bar and points you to the new package.
- Everything else works as it does on the Mac: command blocks, durable SSH sessions, remote files, the Host view with GPUs and listening ports, and port forwarding.
- On Linux the composer shortcut is Shift+Alt+Space.

## Also

- The App icon setting describes the taskbar on Windows and Linux, rather than the Dock.

## Install and update

- **macOS** (Apple Silicon and Intel): the app is not notarized. After the first launch attempt, allow it under System Settings → Privacy & Security → "Open Anyway". GenieTerm 0.4.83 and later update in the app.
- **Linux:** download the AppImage or .deb for your architecture from this release.
- **Windows x64** remains an unsigned preview published on prerelease tags.
