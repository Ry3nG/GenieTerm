# GenieTerm 1.4.2

Process columns in Host can now be resized to show long usernames and other process details. Drag a column header's right edge to adjust its width, or double-click the edge to restore its default size.

## Processes

- **Adjust every column.** Resize User, Command, PID, Status, thread count, CPU and Memory columns. Wide tables scroll horizontally while their headers stay aligned with the process rows.
- **Read full usernames.** Hover over a username to see its complete value.
- **Keep your layout while working.** Column widths remain in place when switching Host tabs. Focus a resize handle and use the arrow keys to adjust it, or Home to restore its default width.

## Security

- Built with Go 1.27.3, which updates certificate verification to distrust compromised intermediate certificates (GO-2026-6809).

## Update

Existing macOS and Linux AppImage installations receive this release through the stable update feed. Linux .deb installations show an update notice with a link to the new package.
