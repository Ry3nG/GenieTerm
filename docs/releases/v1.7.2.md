# GenieTerm 1.7.2

Find a previous command in Command History and press Enter to return to its output, even when the command ran in another tab.

## Command History

Use the Up and Down arrow keys in the search field to select a result. Enter opens the original terminal at the selected command when its output is still available. To reuse the command at your current prompt, choose **Insert**.

## Terminal input

Rapid typing in a newly opened terminal could interrupt input while other tabs were producing output. Command suggestions now refresh at most once per frame as you type.
