01Durable sessions

                    
Close the lid. Your agent keeps working.

                    
A session keeps running on the host through sleep, network changes and restarts. When it reattaches, everything it printed while you were away streams back.

                    
    
                        
  • No tmux to remember
    • 
                        
  • Output from while you were away streams back
    • 
                        
  • Agents, builds, REPLs: anything long

05Everything else

                
And the rest of a good terminal.

                

                    

                        
blocks

                        

                            
Command blocks

                            
Each command keeps its output, status and duration together. Copy it, run it again, or jump to the last one. Underneath, an ordinary xterm session.

                        

                    

                    

                        
genie

                        

                            
The genie helper

                            
Offered the first time you connect to a host. It powers blocks, durable sessions and Host there, and adds genie view and genie edit.

                        

                    

                    

                        
updates

                        

                            
Keeps itself current

                            
Updates arrive in the app on macOS and with the AppImage on Linux. Workspaces and sessions carry over.

                        

                    

                    

                        
LICENSE

06Privacy

                    
No account. No telemetry. No AI service of its own.

                    
Command AI sends a request only when you ask, straight to the AI you chose. Keys and tokens are removed first, a remote host is described only as a remote host, and you can turn it off for any machine.
